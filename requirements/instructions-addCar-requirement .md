# Вимога: додавання автомобіля користувачу

## Початковий стан

- Користувач відкрив QAuto та увійшов через `Guest log in`.
- Після входу доступна кнопка `Add car`.

## Сценарій

1. Натиснути на кнопку `Add car`.
2. У полі Brand обрати `Audi`.
3. У полі Model обрати `TT`.
4. У полі Mileage ввести `12000`.
5. Натиснути кнопку `Add`.

## Очікуваний результат

- Відображається одна картка автомобіля.
- Картка має назву `Audi TT`.
- Бфля назви авто відображається емблема.
- На картці відображається пробіг `12000`.
- У картки є кнопка редагування
- У картки є кнопка `Add fuel expense`
- У картки є кнопка `Update`

## Межі

- Model залежить від Brand.
- Перевіряється додавання авто і відображення картки, а не робота кнопок на створеній картці.
- Точні HTML-атрибути й CSS-класи не задані.
- Ознаки елементів треба підтвердити за поточним UI.
- Якщо картка не створена, модель або бренд відсутні, або UI відрізняється від вимоги, треба зафіксувати blocker, а не вигадувати успішний результат.
