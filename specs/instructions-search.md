# Guest searches instructions for BMW X5

## Перевірена навчальна умова

Гість, який уже ввійшов через `Guest log in`, переходить до розділу
`Instructions`, обирає Brand `BMW` і залежну від нього Model `X5`, запускає
пошук та бачить щонайменше одну картку інструкції для `BMW X5`. На кожній
показаній картці доступна дія `Download`.

## Межі

- Один незалежний UI-сценарій у Chromium.
- Старт через `baseURL` із `playwright.config.ts`.
- Вхід через `Guest log in` є підготовкою; основна перевірка — фільтрація та
  показ інструкцій.
- Перевіряються навігація до `Instructions`, залежність Model від Brand, пошук
  за `BMW` → `X5`, результати та доступність `Download`.
- Завантаження або перевірка вмісту PDF не входить до сценарію.
- Не додавати registration, API-виклики, credentials, зміну config або інші
  сценарії.

## Тестові дані

- Brand: `BMW`.
- Model: `X5`.

## Сценарій: гість знаходить інструкції для BMW X5

### Початковий стан

1. Новий чистий browser context у Chromium.
2. Користувач відкриває кореневу сторінку через налаштований `baseURL`.
3. Дані попередніх пошуків не використовуються.

### Кроки

1. Натиснути доступну кнопку `Guest log in`.
2. У лівому меню відкрити розділ `Instructions`.
3. У полі Brand обрати `BMW`.
4. Переконатися, що поле Model стало доступним і містить варіант `X5`.
5. У полі Model обрати `X5`.
6. Натиснути `Search`.
7. Знайти показані картки інструкцій.
8. Для кожної показаної картки перевірити, що її назва стосується `BMW X5`.
9. Для кожної показаної картки перевірити наявність доступного посилання або
   кнопки `Download`.

### Очікуваний результат і критерії успіху

- Розділ `Instructions` відкрито.
- Вибір `BMW` дає змогу обрати залежну модель `X5`.
- Після пошуку показано щонайменше одну картку інструкції.
- Назва кожної показаної картки відповідає `BMW X5`.
- У кожній показаній картці є доступна дія `Download`.

### Умови невдачі

- Немає пункту або сторінки `Instructions`.
- Після вибору `BMW` модель `X5` недоступна.
- Після пошуку не показано жодної картки.
- Хоч одна показана картка не стосується `BMW X5`.
- Хоч на одній показаній картці відсутня доступна дія `Download`.

- Точні ролі, accessible names, locator-и, структура картки та фактична

  Playwright CLI після `APPROVE CLI INSPECTION`.

## Позначки ризиків

- **FACT:** вимога визначає пару `BMW` → `X5`, пошук, результати та дію
  `Download`.
- **FACT:** HTML-атрибути, CSS-класи та точні ознаки елементів не задані.
- **ASSUMPTION:** назву картки можна перевіряти через видимий текст; конкретний
  спосіб перевірки буде обрано лише після UI-inspection.
- **RISK:** поточний UI може не містити результатів для `BMW X5` або
  відрізнятися від вимоги.
- **QUESTION:** який саме доступний елемент є дією `Download` — посилання чи
  кнопка — має встановити UI-inspection.
- **STOP:** якщо UI не підтвердить наявність `BMW`, `X5`, результатів або
  `Download`, не вигадувати locator-и чи expected result; зафіксувати blocker.
